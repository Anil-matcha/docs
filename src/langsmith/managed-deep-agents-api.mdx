Use the Managed Deep Agents API to create hosted Deep Agents, manage durable threads, and stream runs from LangSmith.

<Note>
    Managed Deep Agents is in private preview. [Join the waitlist](https://www.langchain.com/langsmith-managed-deep-agents-waitlist) to request access. For an end-to-end walkthrough with request examples, see [Deploy Managed Deep Agents](/langsmith/deploy-managed-deep-agent).
</Note>

For a conceptual introduction to the underlying framework, see the [open source Deep Agents docs](/oss/deepagents/overview).

## Authentication

Requests require a LangSmith API key for a workspace with Managed Deep Agents private preview access. To create one, follow the [Create an API key](/langsmith/create-account-api-key) guide. Pass the key with each request:

```txt
X-Api-Key: <LANGSMITH_API_KEY>
```

## Base URL

The private preview API is served from `https://api.smith.langchain.com/v1/deepagents`. Self-hosted and Hybrid deployments are not supported in private preview.

## Verify access

Confirm your API key and workspace have private preview access before working through the route reference:

```bash
curl https://api.smith.langchain.com/v1/deepagents/agents \
  -H "X-Api-Key: $LANGSMITH_API_KEY"
```

A `200` response with a (possibly empty) list of agents confirms access. A `401` or `403` means the workspace is not enrolled in the preview.

## Resource groups

| Resource group | Purpose |
| --- | --- |
| Agents | Create and manage Managed Deep Agent resources. |
| Threads | Create and manage durable thread state for Managed Deep Agents. |
| Runs | Start and stream Managed Deep Agent runs on threads. |

## Private preview scope

Private preview covers the agent lifecycle, threads, and runs. Other LangSmith Deployment endpoint groups, including integrations, auth, triggers, skills, and sandboxes, are out of scope for this preview.
